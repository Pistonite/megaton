# Tutorial

This section covers setting up a new Megaton project and compiling it
using the Megaton build tool.

At this point, you should installed Megaton by following the
[installation guide](../install.html).


You can run ```bash`megaton -vV``` to do an installation health-check.
The output will look something like this:

```
:: megaton version 0.3.1 (ef03d596afa627d709e92ac62cd57bf6682508b4)
D] MEGATON_HOME=/home/yourusername/.cache/megaton
D] devkita64: gcc 16.1.0
D] cxxbridge: 1.0.197
D] rust (host): 1.100.0 (0ef1bc386059596dada8fb65b50425aab2ea637a)
D] rust (megaton): 1.100.0-dev (0d31508599a7814a7044e9a7a871e3dc5f037753)
D] build_dep/git: <installed>
D] build_dep/ninja: <installed>
D] build_dep/cmake: <installed>
```
